# Simple Login App

This is a simple Java console-based login application.

## 📁 Files Included

- `SimpleLoginApp.java` — Java source code for the login functionality.
- `diagram.pdf` — contains system or UML diagrams related to the project.

## ▶️ How to Run (Using NetBeans)

### Requirements:
- Apache NetBeans IDE
- JDK installed and configured in NetBeans

### Steps:

1. Open NetBeans IDE.
2. Go to `File` > `Open Project`.
3. Navigate to the folder containing the `SimpleLoginApp` project and open it.
4. In the **Projects** panel, expand the project and right-click on `SimpleLoginApp.java`.
5. Click `Run File` to execute the program.
